# body-dimension-forge

公開人体計測データを基に、創作キャラクターやアバター向けの身体寸法を補完するためのプロジェクトです。

## 現在の進捗

- 第1版の開発方針、仕様、データ出典候補、判断記録、モデル報告、テスト計画を文書化する土台を作成済みです。
- Webアプリ本体はまだ実装していません。
- 推定式、係数、学習済みモデル、外部データはまだ追加していません。

## 開発段階

現在は初期設計段階です。公開人体計測データを測定項目ごとに「解析開始」「モデル採用」「完成品搭載・配布」の3ゲートで判定します。解析開始可は正式採用や完成品利用を意味しません。第0.1版では胸囲を自動推定せず、手入力値は固定保持し、空欄は補完しません。自動推定候補はウエストとヒップですが、モデル、推定式、係数はまだ作成しません。

## 注意事項

- 本プロジェクトは成人・人間・現実に近い体型を対象とします。
- 医療診断、健康評価、美容上の評価には使用しません。
- 不明点は推測で補わず、「未確定」として記録します。
- 入力された値、とくに固定チェックされた値はアプリが勝手に変更しない方針です。
- 仕様変更の理由と影響範囲は `docs/DECISIONS.md` に記録します。

## ドキュメント

- `docs/INDEX.md`: 文書の場所、役割、正本を示す索引
- `docs/SPEC.md`: 第1版仕様と第0.1版暫定範囲
- `docs/DECISIONS.md`: 判断記録
- `docs/DATA_SOURCES.md`: データ出典候補と採否記録
- `docs/DATA_ACCEPTANCE_CRITERIA.md`: データの必須条件と項目別の3段階採用判定ゲート
- `docs/MODEL_REPORT.md`: モデル検討・評価記録
- `docs/TEST_PLAN.md`: テスト計画
