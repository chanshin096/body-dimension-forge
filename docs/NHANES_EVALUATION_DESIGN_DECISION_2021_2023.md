# NHANES 2021–2023 3-way評価設計の正式採否（Bゲート実行6）

## 1. 判定と適用範囲

本書は、Bゲート実行4・5で確認した「15層・30 pseudo-PSUのfull examined survey designを維持し、層を丸ごと3群へ割り当て、群をdomain/subpopulationとして評価する」候補を、第0.1版の学習・検証・封印最終試験へ正式採用できるか判断する正本である。対象は将来のウエスト `BMXWAIST` とヒップ `BMXHIP` の予測評価設計だけである。本工程ではモデル学習、予測、性能値計算、目的値分布比較、最終試験の開封を行っていない。

**必須判定は C「固定3-way方式を不採用とし、別方式を正式候補にする」**とする。

別方式の正式候補は、**NHANES 2021–2023の15層・30 pseudo-PSUを分割せずdevelopmentに用い、最終試験には将来確保する独立データを用いる方式**である。これは評価方式の候補を定めるだけで、モデル、resampling方式、評価指標のCI法、独立データを採用したものではない。独立最終試験データとdevelopment内resamplingの両方を事前承認できるまでは、モデル学習へ進まない。5項目のA可・B保留・C保留も変更しない。

## 2. 判断根拠

### 2.1 3群を米国成人母集団の評価domainとは扱わない

NCHSのdomain分析は、年齢群など、full sample内に現れる部分母集団について、正の分析ウェイトを持つ全観測をdesignに残して分散を推定する手順を与える。一方、今回の群indicatorは母集団属性ではない。公開masked variance stratum自体を昇順で3分し、各群を構成する5層を残り10層から構造的に分離した**解析者作成の標本区分**である。

したがって、full designへdomain indicatorを渡せることは必要な実装条件ではあっても、各5層が米国成人母集団に対する独立かつ代表的な確率標本であること、または群間性能差を一般化できることの根拠にはならない。公開ウェイトはNHANES full sampleの推定用であり、この3群を独立標本にするため作成・校正されたものではない。masked variance strataを割当キーに使うことへのNCHSの方法論的承認も確認できていない。

このため、群内に正のcomplete case件数がありRでTaylor分散を計算できても、各群の推定値を「米国成人母集団に対するvalidation/final-test性能」と解釈しない。物理部分designも、10層を削除し新しい確率標本とみなす根拠がないため、Bゲート実行5どおり不採用を維持する。

### 2.2 df=5は計算可能性を示すだけで、採用に十分でない

各群のsubgroup design dfは、対象観測を含む10 PSU−5層の **5** とする。full designのdf=15を流用しない。ただし、df=5で有限なSE/CIが返ることを、精度、校正、頑健性または母集団代表性の確認とはみなさない。

| 指標 | df=5で許容する範囲 | 正式評価での判定 |
| --- | --- | --- |
| mean / mean error | 固定済み変数のTaylor linearized meanについて、`t(df=5)`による探索的CIの計算可否を構造検査できる | 3-way最終評価には不採用。幅やcoverageを確認してから方式を選ぶことも禁止 |
| MAE | 固定済みabsolute errorのsurvey meanとして同じ計算法を将来検証できる | 3-way最終評価には不採用 |
| MSE | 固定済みsquared errorのsurvey meanとして同じ計算法を将来検証できる | 3-way最終評価には不採用 |
| RMSE | MSEからの平方根変換とdelta method等を、結果を見る前に別途根拠化する必要がある | CI法未決定。即興の変換、正規近似、負の下限切上げは禁止 |
| quantile | `survey`の実装でdf=5を明示したCIの機械的計算可否は確認済み | 非滑らか統計であり、方法別挙動と精度の根拠がないため正式評価には不採用 |
| coverage | 固定した予測区間indicatorのsurvey proportionなら点推定・Taylor CIの候補になり得る | 予測区間生成法、名目水準、CI法が未決定であり不採用 |
| subgroup・年齢帯・尾部分位点・候補差・その他 | domainを重ねるほど寄与PSU・層、自由度、有効件数がさらに減り得る | 事前に全必須domainで設計対応CIを保証できないため不採用 |

低自由度だけを一律の数学的禁止条件にはしないが、今回の設計では、(1)代表性の根拠不足、(2)必須指標ごとのCI法未確定、(3)生コード・年齢帯を重ねた評価不能リスク、(4)多数のモデル・入力セット比較に対する不確実性、が同時に残る。この組合せを停止条件とする。結果を見て指標、区分、CI法、自由度、群割当を変更して救済してはならない。

## 3. nested resamplingの判定

現在の15層×2 PSU構造では、要求を同時に満たすnested resamplingは**不成立**とする。

- 層内2 PSUを外側foldへ分けると、fold/domainごとに1 PSU/層となり、Taylor分散に必要な層内PSU間変動を評価できない。lonely PSU補正は採用しない。
- 2 PSUを一緒に保って層単位で外側foldへ分けると、foldは一部のmasked strataだけになり、3-way候補と同じ代表性問題と低dfを生じる。
- その外側trainingをさらに内側foldへ分けると、PSU非重複、各保持層2 PSU、十分な層数を同時に維持できない。
- PSUを内側fold間で再利用すれば非重複条件を破り、validationを反復利用して選択すれば過適合を防げない。封印群を調整へ転用することも禁止する。

よって外側/内側fold数、PSU・stratum割当、再利用規則を仮置きしない。fold数を減らす、同じPSUを再利用する、分散だけfull df=15とする、lonely PSUを便宜補正する案は不採用である。将来、replicate-weight法、survey bootstrap等を検討する場合も、本書だけでは成立とせず、NCHS設計との整合、選択バイアス、分散推定、再現性をモデル実行前の独立工程で承認する。

## 4. 代替案の比較と正式候補

| 方式 | 判断 | 理由 |
| --- | --- | --- |
| 固定3-way層分割＋full design/domain | **不採用** | 各群は解析者がmasked strataから作った5層だけの区分であり、母集団属性のdomainでも独立代表標本でもない。df=5とnested resampling不成立も重なる |
| 2-way PSU split＋development内resampling | **不採用** | 層内で分ければ1 PSU/層、層ごと分ければ層欠落となる。さらにdevelopment内のnested分割余地がない |
| design-aware grouped cross-validation | **未決定（現構造で通常fold分割は不採用）** | 「grouped」という名称だけではsurvey designを維持できない。PSU分離と層内分散を両立するfold構成が成立しない |
| NHANES全体をdevelopment＋将来の独立最終試験 | **正式候補** | NHANESの公式15層・30 PSU designをvalidation/testの都合で切断せず、最終確認をdevelopmentと独立したデータへ分離できる。採用理由はデータ量最大化ではなく、設計推論と最終試験独立性を両立できる可能性である |

正式候補でも、NHANES全体を一度学習へ使えば、同じcycleを独立最終試験とは呼ばない。development内で候補選択に用いるresamplingは未決定であり、単一のfull-data適合度をvalidationの代用にしない。独立データは、対象母集団、測定定義、入力定義、時点、QC、標本設計、ウェイト、利用条件が事前に確認され、同じ性能指標と採否規則を適用できなければ最終試験に採用しない。

## 5. 最終試験の封印規則

現在の3-way診断候補は正式splitではなく、**最終試験として開封も再利用もしない**。将来の独立データを採用できた場合だけ、次をすべて登録してから受領・目的値参照・性能計算へ進む。

1. データ名、cycle/版、公式取得元、対象母集団、測定・入力定義、利用条件、設計変数とウェイトを文書・commitで固定する。
2. 課題、生コードdomain、QC、入力セット、最終候補を一つに絞る手順、全指標、CI法、自由度、数値採否閾値、失敗時の扱い、software版を固定する。
3. final-testデータの目的変数、目的値分布、性能値へdevelopment担当者が接触できないアクセス分離を定める。ハッシュ、取得日時、実行commit、実行者、開封日時を監査記録へ残す。個人値・`SEQN`一覧は保存しない。
4. 承認済み単一候補について一度だけ評価する。不合格後に同じtestを見てモデル、閾値、指標、区分またはCIを変えて再試験しない。

独立データが未確保の現在は、封印対象、アクセス主体、保存場所、暗号鍵管理は**未確定**である。未確定のまま「封印済み」と表示しない。

## 6. 未決定事項、停止条件、次工程

### 未決定事項

- development内でモデル選択とハイパーパラメータ選択を評価するdesign-aware resamplingまたは別の選択法。
- 独立最終試験データの候補、対象母集団・測定定義・標本設計の整合、必要精度、利用条件。
- MAE、MSE/RMSE、quantile、coverage、候補差のdesign-based CI法と、全数値採否閾値。
- 個人予測区間の生成法と名目水準、用途側の許容誤差・測定再現性。

### 即時停止条件

- 現在の3-way診断群をtraining/validation/final testとして使用する、または性能・目的値分布を参照する。
- masked strataの一部から得た結果を、校正根拠なしに米国成人母集団性能と表示する。
- df=15の流用、lonely PSU補正、個人ランダム分割、ウェイト再正規化、PSU再利用、結果を見たfold・seed・指標・CI法の変更。
- design-aware development選択法または独立最終試験のどちらかが未承認のままモデル学習へ進む。

### 次工程へ進める条件

次工程はモデル学習ではなく、**正式候補の成立条件確認**である。次の二点を同一の事前計画として人間が承認した場合だけ、評価設計を確定する次判断へ進める。

1. 15層・30 PSUのfull designを壊さず、候補選択によるoptimismを扱えるdevelopment内手法について、公式設計との整合、fold/replicate単位、再利用規則、CI・比較法、software版、停止条件を固定する。
2. NHANES developmentから独立した最終試験データについて、取得可能性、対象母集団、測定・入力定義、標本設計・ウェイト、必要精度、利用条件、封印・一回評価手順を承認する。

どちらかを満たせなければ判定D相当として評価設計の確定を停止し、Bは保留を維持する。この工程の結論だけでB/Cゲートを通過させない。
