# データ採用判定基準

## 1. 目的と適用単位

この文書は、候補データについて、後工程で必要な条件を前工程の停止条件に混ぜずに判断するためのゲートである。データセットを一括判定せず、**身長、体重、BMI、胸囲、ウエスト、ヒップの測定項目ごと**に、解析開始、モデル採用、完成品搭載・配布を別々に判定する。

現時点の判定は既存の `docs/NHANES_AUDIT.md`、`docs/ANSUR_II_AUDIT.md`、`docs/DATA_SOURCES.md` だけに基づく。新たなインターネット調査、生データ取得・分析は行っていない。3ゲートへの分割は監査基準の緩和ではなく、あるゲートの通過は後続ゲートの通過や正式採用を意味しない。NHANESとANSUR IIはいずれも正式採用へ変更しない。

## 2. 3ゲートと判定状態

| ゲート | 判定対象 | 通過の意味 | 通過に必要な条件 | 停止条件 |
| --- | --- | --- | --- | --- |
| **A. 解析開始** | 生データを取得し、内容確認、前処理検討、試験的な統計分析を開始してよいか | 限定した解析作業の開始だけを許す。モデル採用、完成品利用、公開または再配布は許可しない | 正式な取得元、対象項目の存在、解析に必要な変数説明・測定定義・単位、対象集団の基本情報、欠損・QCの確認可能性、解析目的と利用条件上の可否を確認し、対象範囲を記録する | 対象項目が候補に存在しない、取得元・定義・単位・品質の確認に必要な情報が不足して解析を正当化できない、または取得・解析が利用条件に反する |
| **B. モデル採用** | 成人抽出、欠損・QC処理、統計区分、標本設計、前処理、評価方法を決め、試験結果を採用できるか | 当該項目・用途のモデル候補を採用できる。完成品への搭載・配布は許可しない | 再現可能な処理と評価方法を決定し、項目別利用可能数、標本ウェイト・層化・クラスタリング、一般化の限界を扱い、事前に定めた採用基準を試験結果が満たす | 処理や評価を再現できない、対象用途へ妥当な評価ができない、要求精度を満たさない、または入力項目の代用・根拠のない結合を要する |
| **C. 完成品搭載・配布** | データ、加工データ、係数またはモデルを完成品へ搭載し、公開・商用利用・再配布してよいか | 確認した利用条件と引用方法の範囲内で、明記した成果物と配布形態に限り許可する | 必須の引用方法、取得・加工、成果物への搭載、公開、商用利用、再配布、帰属、免責を確認し、実際の配布形態が条件を満たす | 利用条件または引用方法が未確認、想定する搭載・公開・商用利用・再配布が禁止、あるいは遵守方法を確定できない |

各ゲートでは次の状態とともに、理由、通過条件、停止条件を記録する。

| 状態 | 定義 |
| --- | --- |
| **可** | 当該ゲートの条件を確認済みで、その工程に限り進める |
| **保留** | 必要条件の一部が未確認または未決定であり、その工程へ進めない |
| **不可** | 当該候補・項目では停止条件に該当し、その工程へ進めない。別 component や新しい公式根拠は別候補として再監査する |

「項目が存在する」は変数名の存在だけを確認した状態であり、「測定定義まで確認済み」とは区別する。存在だけではいずれの後続ゲートも通過させない。

## 3. ゲート判定で確認する事項

次の事項を該当するゲートで証拠とともに確認する。データ全体の情報は共有できるが、正式変数名、単位、測定定義、欠損・品質、前処理、評価、成果物の扱いは項目ごとに記録する。

| 確認事項 | 主に判定するゲート | 確認・記録する内容 |
| --- | --- | --- |
| 公式または信頼できる取得元、調査名・主体・年 | A | 配布主体、正式調査名、実施責任、cycle・版、取得場所 |
| 対象集団、標本の基本情報 | A（詳細設計はB） | 年齢範囲、地域、選抜・除外、抽出設計、一般成人との差 |
| 正式変数名、保存単位、測定方法・位置 | A | 配布データと説明の一致、形式、丸め、姿勢、機器、衣服、ランドマーク、呼吸相、直接測定か派生値か |
| 欠損・測定不能・異常値・QC | A（処理決定はB） | 値、comment・statusコード、非対象、補完、編集、QC、確認可能性 |
| 成人抽出、統計区分、項目別標本数 | B | 成人・項目・区分ごとの利用可能数、男女等のコードと層別・結合方針。男女を無条件に結合しない |
| 再現可能な前処理と標本設計 | B | 結合キー、単位処理、欠損・QC除外、派生値、ウェイト、層化、クラスタリング |
| 評価と適用限界 | B | 分割・外部検証、指標、採用基準、代表性、一般化可能性、定義差、対象外集団 |
| 利用条件と引用方法 | C（取得・解析可否はAでも確認） | 取得、加工、搭載、公開、商用利用、再配布、帰属、免責、データ名・版・URL・参照日・手順書 |

**NHANES各項目の通過条件・停止条件**

- Aの通過条件は表の確認済み事実、停止条件は対象変数の不存在、定義・単位・QCを確認できないこと、または解析が利用条件に反すること。胸囲は `BMX_L` に対象変数がないため停止する。
- Bの通過条件は成人抽出、項目別件数、欠損・QC、統計区分、複雑標本設計、再現可能な前処理、用途別評価方法を決定し、試験結果が採用基準を満たすこと。これらを決定・評価できない、要求精度を満たさない、胸囲を推定・代用する、または定義差を処理できない場合は停止する。
- Cの通過条件は引用と、加工データ・係数・モデルの搭載、公開、商用利用、再配布を含む実際の利用条件を確認すること。未確認、用途不許可、または遵守不能なら停止する。

## 5. 全ゲートに適用する停止規則

- 軍人標本であるANSUR IIを一般成人の代表標本として扱わない。適用可能性を別途評価できなければBで停止する。
- 男女または公開統計区分は、変数定義、標本構造、項目構成、用途上の扱いを確認するまで結合しない。
- 利用条件が未確認のデータを、完成品で使用可能とは断定せずCを通過させない。
- 胸囲をバストへ、ヒップ周囲長を `hip breadth` へ読み替えない。
- 項目の存在だけを根拠に、測定定義、単位、品質または用途適合性が確認済みとは扱わない。
- Aが可でもB・Cは独立に判定する。Bが可でもCは独立に判定する。
- B通過前にモデル、推定式または係数を採用せず、C通過前に完成品へ搭載・公開・商用利用・再配布しない。

## 6. 現在の結論

NHANES `BMX_L` は、身長、体重、BMI、ウエスト、ヒップについて既存監査で変数、単位、測定または派生定義、品質情報を確認できているため、Aを**可**とする。成人抽出、前処理、標本設計、評価方法と試験結果が未決定のためBは**保留**、利用条件と引用方法が未確認のためCは**保留**であり、正式採用ではない。胸囲は当該 component に変数がないため、この候補ではA・B・Cすべて**不可**とするが、NHANES全体に胸囲が存在しないとは断定しない。

ANSUR IIは胸囲候補として残すが、公式変数説明、正式な取得元、測定定義、単位、欠損・QC、利用条件等が不足しているため、全項目のA・B・Cを**保留**とし、正式採用しない。男性データと女性データを無条件に結合しない。
