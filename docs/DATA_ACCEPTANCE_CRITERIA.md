# データ採用判定基準

## 1. 目的と適用単位

この文書は、候補データをモデル、係数または公開Webアプリに使用してよいかを判定するゲートである。データセットを丸ごと一括採用せず、**身長、体重、BMI、胸囲、ウエスト、ヒップの測定項目ごと**に判定する。

現時点の判定は既存の `docs/NHANES_AUDIT.md`、`docs/ANSUR_II_AUDIT.md`、`docs/DATA_SOURCES.md`だけに基づく。新たなインターネット調査、生データ取得・分析は行っていない。NHANESとANSUR IIはいずれも正式採用へ変更しない。

## 2. 採用状態

| 状態 | 定義 | 状態を移す条件 |
| --- | --- | --- |
| **未調査** | 採用判断に必要な調査を開始していない | 根拠資料を定め、監査を開始したら「監査中」へ移す |
| **監査中** | 一部の根拠を確認したが、必須条件が未充足または採否判断が未完了 | 全必須条件を項目単位で満たし、判断記録を残した場合だけ「採用可能」へ移す。停止条件に該当すれば「使用不可」へ移す |
| **採用可能** | 当該項目について全必須条件を証拠で確認し、用途・前処理・評価条件を明記し、採用判断を記録した | 根拠、利用条件、定義または品質に重大な問題が判明したら再監査し、「監査中」または「使用不可」へ戻す |
| **使用不可** | 当該候補・項目が必要な変数を持たない、用途と両立しない、または停止条件に該当する | 新しい公式根拠や別componentなど、従来と異なる候補が示された場合に限り、候補を区別して再監査する |

「項目が存在する」は変数または項目名の存在だけを確認した状態であり、「測定定義まで確認済み」とは区別する。存在だけでは採用可能にしない。

## 3. データ全体および項目別の採用必須条件

以下をすべて証拠とともに確認する。データ全体に関する条件は同じデータセットの各項目判定で共有できるが、正式変数名、単位、測定定義、欠損・品質、前処理および評価情報は項目ごとに確認する。

| 必須条件 | 採用前に確認・記録する内容 |
| --- | --- |
| 公式または信頼できる配布元 | 配布主体、公式性または信頼性、現行の配布場所と配布継続性 |
| 調査名と実施主体 | 正式調査名、実施・管理主体、データ作成責任の範囲 |
| 対象集団 | 年齢範囲、地域、選抜・除外、抽出設計、一般成人との差 |
| 調査年 | 収集開始・終了時期、cycleまたは版 |
| 標本数 | 全体件数だけでなく、対象成人・項目・統計区分ごとの利用可能件数 |
| 男女または統計区分の扱い | 変数名、コード、区分の意味、層別・結合方針。男女を無条件に結合しない |
| 正式な変数名 | 配布データとコードブックで一致する正式名。名称の類似だけで割り当てない |
| 保存単位 | 元の単位、保存形式、精度、丸め、換算が必要な場合の公式根拠 |
| 測定方法と測定位置 | 姿勢、機器、衣服、ランドマーク、テープ経路、呼吸相、直接測定か派生値か |
| 欠損値、測定不能、異常値、品質管理の扱い | 値・comment・statusコード、非対象、除外、補完、編集、QC、異常値判断 |
| 利用条件 | 取得、加工、商用・公開利用、再配布、帰属、免責等。未確認なら公開アプリに使用可能と断定しない |
| 引用方法 | 必須の引用形式、データ名・版・URL・参照日・手順書等の記載方法 |
| 一般成人やアバター用途へ適用する際の限界 | 代表性、一般化可能性、用途間の定義差、対象外集団、精度上の限界 |
| 再現可能な前処理方法 | 対象抽出、結合キー、単位処理、欠損・QC除外、派生値、標本設計の扱いを第三者が再現できる手順 |
| 評価に必要な情報 | 評価対象、分割・外部検証、指標、採用基準、標本ウェイト、層化・クラスタリング、項目別利用可能数 |

必須条件のいずれかが未確認であれば「採用可能」へ移さない。採用条件を満たさない状態では、モデル作成、係数決定、生データ分析またはWebアプリ実装へ進まない。

## 5. 判定時に常に適用する停止規則

- 軍人標本であるANSUR IIを、一般成人を代表する標本として扱わない。適用可能性を別途評価できなければ使用を止める。
- 男女または公開統計区分は、変数定義、標本構造、項目構成、用途上の扱いを確認するまで結合しない。
- 利用条件が未確認のデータを、公開アプリで使用可能とは断定しない。
- 胸囲をバストへ、ヒップ周囲長を `hip breadth` へ読み替えない。
- 項目の存在だけを根拠に、測定定義、単位、品質または用途適合性が確認済みとは扱わない。
- いずれかの必須条件が未充足の項目から、モデル、推定式または係数を作らない。

## 6. 現在の結論

NHANESは身長、体重、BMI、ウエスト、ヒップについて測定定義まで確認が進んでいるが、利用条件、成人部分集合の再現可能な前処理、項目別評価が未確認であるため**監査中**である。`BMX_L`は胸囲変数が確認できないため、同componentを胸囲候補として使う判定は**使用不可**である。

ANSUR IIは身長、体重、胸囲の存在を確認した段階に留まり、その他の項目は存在も未確認である。測定定義、保存単位、欠損・QC、利用条件、一般成人・アバター用途への評価が不足しているため、全項目を**監査中**とし、正式採用しない。
