# NHANES 2021–2023 結合安全性・成人候補・欠損/QC基礎集計（Aゲート実行2）

## 1. 目的・範囲

PR #7で受入検査したCDC/NCHS公式配布物 `BMX_L.xpt` と `DEMO_L.xpt` だけを用い、B「モデル採用」の判断材料となる集計件数を再現可能に確認した。機械可読な正本は [`data/manifests/nhanes_2021_2023_join_qc_summary.json`](../data/manifests/nhanes_2021_2023_join_qc_summary.json)、実行スクリプトは [`scripts/summarize_nhanes_join_qc.py`](../scripts/summarize_nhanes_join_qc.py) である。

この作業はAゲートで許可された限定分析である。欠損補完、値の変更、異常値除外、ウェイト適用、母集団推定、相関、回帰、推定式、係数、モデル作成・評価は行っていない。結合済み行データ、個人の `SEQN` 値または一覧は保存していない。

## 2. 再実行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-analysis.txt
.venv/bin/python scripts/download_nhanes_raw.py  # 生データがない場合
.venv/bin/python scripts/summarize_nhanes_join_qc.py
```

取得元は既存ダウンロードスクリプトが許可する `wwwn.cdc.gov` だけである。生データは `data/raw/` に置かれ、Git管理対象外である。

## 7. 標本設計変数

3変数はいずれも結合結果に存在し、全年齢・18歳以上・20歳以上の全候補で欠損は0件だった。`WTMEC2YR` は連続ウェイト値なので個別値の度数を保存せず、全年齢8,860件、18歳以上6,337件、20歳以上6,064件がすべて正、ゼロ・負値は0件だった。`SDMVSTRA` と `SDMVPSU` は生コード別件数をmanifestに保存した。全年齢では `SDMVSTRA` のコード173–187が各498–682件、`SDMVPSU` はコード1が4,540件、コード2が4,320件だった。

これは存在・欠損・基本コード件数の確認だけである。ウェイト適用、層化・クラスタリングを用いた推定、加重平均、母集団推定は実施していない。値域による採否も決めていない。

## 8. 未決定事項と次工程

次の事項はすべて**未確定**である。

- 成人を18歳以上または20歳以上のどちらとするか（あるいは別条件とするか）。
- `RIAGENDR` コード別データをどう扱い、結合評価を許すか。
- 測定値欠損、`BMDSTATS`、各commentコードをどの規則で採用・除外するか。
- BMI派生値と身長・体重のQCをどう連動させるか。
- `WTMEC2YR`、`SDMVSTRA`、`SDMVPSU` を分析目的に対してどう適用するか。
- 一般化の限界、評価方法、事前採用基準、利用条件と引用方法。

次工程では、人間が年齢候補ごとの件数差、`RIAGENDR` コード別の項目利用可能数、測定状態・commentコード、複雑標本設計と分析目的を確認し、処理案の採否と不採用理由を明示する必要がある。この集計だけで処理方針やモデル採用を決めてはならない。

身長、体重、BMI、ウエスト、ヒップのB「モデル採用」とC「完成品搭載・配布」はいずれも**保留のまま**である。胸囲のゲート状態、ANSUR IIの全ゲート状態も変更していない。
