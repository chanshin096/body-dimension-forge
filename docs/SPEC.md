# 仕様書 v1

## 目的

公開人体計測データを基に、創作キャラクターやアバター向けの身体寸法を補完する。

## 対象

- 成人
- 人間
- 現実に近い体型
- cm、kg単位
- 医療診断や健康評価には使用しない

## 入力

- キャラクター名：任意。空欄可能。計算には使わない。
- 統計モデル上の男性／女性区分
- 年齢
- 身長
- 体重
- 胸囲
- ウエスト
- ヒップ

## 固定チェック

- 固定チェックは、身長、体重、胸囲、ウエスト、ヒップに付ける。
- 手入力した値は原則として固定する。
- 推定値は未固定とする。
- 再計算時は未固定項目だけ更新する。
- 固定値はアプリが勝手に変更しない。
- 全項目固定の場合はエラーにせず、整合性確認のみ行う。
- BMIは固定不可とし、身長と体重から自動計算する。

## 予定出力

- BMI
- 未固定または空欄の胸囲、ウエスト、ヒップ
- 推定範囲
- 入力値、推定値、自動計算値の区別
- 警告
- 使用データとモデル名
- 結果コピー

## 第1版で扱わないもの

- 子ども
- 人外や極端なデフォルメ体型
- 股下、座高、腕長、肩幅
- 画像からの測定
- 3Dモデル生成
- 医療・健康・美容上の評価
- 根拠のない「痩せ型」「筋肉質」補正

## データ候補

- NHANES：ウエスト、ヒップなどの候補
- ANSUR II：胸囲などの候補

ただし採用は未確定とし、測定定義、対象集団、利用条件、精度を調査してから決定する。

## 未確定事項

- 各測定項目の厳密な定義
- 利用条件と引用方法
- モデル種別
- 評価指標と採用基準
- 警告表示の具体的な閾値
