## 正本と将来の総合仕様書の扱い

- 各分野の正本は、上表に示したそれぞれの担当文書とする。
- 後日作成する総合仕様書・完成仕様書は、作成したマイルストーン時点のスナップショットとして扱い、担当文書の代わりにはしない。
- 総合仕様書・完成仕様書と担当文書が食い違った場合は、どちらかへ自動的に合わせない。差異と根拠を確認し、判断を `docs/DECISIONS.md` に残してから必要な文書を修正する。
- 文書を追加、削除、改名した場合は、必ずこの `docs/INDEX.md` を更新する。
