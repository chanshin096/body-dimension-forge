# NHANES 2021–2023 欠損・測定状態・QC処理方針（Bゲート実行1）

## 1. 目的、対象、状態

PR #10で決定した第1版成人対象 `RIDAGEYR >= 20` を維持し、NHANES August 2021–August 2023 `BMX_L` の `BMXHT`、`BMXWT`、`BMXBMI`、`BMXWAIST`、`BMXHIP` に限って、欠損・測定状態・comment・QCの暫定処理を決めた。`RIAGENDR=1` と `RIAGENDR=2` は生コード別に保持し、名称を付けず、無条件に結合しない。

これは **Bゲート実行1** であり、B「モデル採用」そのものの判定ではない。5項目のB・Cはすべて**保留**のままである。胸囲、ANSUR II、標本ウェイト・層化・クラスタリングの最終方針は変更しない。モデル、推定式、係数を作成していない。

詳細集計の機械可読な正本は [`data/manifests/nhanes_2021_2023_missing_qc_policy.json`](../data/manifests/nhanes_2021_2023_missing_qc_policy.json)、再現スクリプトは [`scripts/summarize_nhanes_missing_qc.py`](../scripts/summarize_nhanes_missing_qc.py) である。本書には判断に必要な全体件数だけを掲げ、`RIAGENDR` 生コード別を含む詳細値は重複掲載しない。

## 2. 公式資料で確認した事項

確認にはCDC/NCHS公式の [Body Measures (BMX_L) codebook](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/BMX_L.htm) と [2021 Anthropometry Procedures Manual](https://wwwn.cdc.gov/nchs/data/nhanes/public/2021/manuals/2021-Anthropometry-Procedures-Manual-508.pdf) を用いた（再確認日: 2026-08-06）。

- 5項目の対象年齢は、身長・BMI・ウエストが2–150歳、体重が全年齢、ヒップが12–150歳と記載される。したがって `RIDAGEYR >= 20` の抽出後に年齢だけを理由とする非対象者はいない。ただし screening と examination の時点差は残る。
- 数値列の `.` は欠損であり、補完は実施されていない。
- `BMDSTATS` は 1=年齢群に必要なデータが完全、2=身長・体重のみ、3=その他の部分検査、4=身体計測データなしである。
- 各関連commentの code 1 は `Could not obtain` である。`BMIHT` code 3 は `Not straight`、`BMIWT` code 3 は `Clothing`、code 4 は `Medical appliance` である。commentの欠損は測定値の欠損と同義ではない。
- BMIは体重と身長から計算された派生値であるため、`BMXBMI` では `BMIHT` と `BMIWT` の双方を連動確認する。
- CDC/NCHSは極端値を確認し、非現実的と判断した値を削除した一方、値を変更せず補完もしなかったと説明する。また、分析者に分布を確認して包含可否を検討するよう求めている。この記述だけを根拠に追加の閾値や自動除外規則は作らない。

## 3. 分類規則と優先順位

各成人レコードを項目ごとに次の相互排他的な順序で1区分へ割り当てる。語尾の **使用可能／除外／保留** が第1版の暫定処理である。

1. 測定値が欠損し、当該項目のcomment code 1がある: **測定不能として除外**。
2. 測定値が欠損し、`BMDSTATS=4`: **身体計測データなしとして除外**。未実施等の個別理由までは公式資料から確認できないため推測しない。
3. 上記以外の測定値欠損: 理由が確認できないため **その他欠損として保留**。
4. 測定値があり、`BMIHT=3` または当該項目に関係する `BMIWT=3/4`: 品質への影響量と用途上の許容条件が未決定のため **comment付き有効値として保留**。
5. 測定値があり、上記commentがない: **使用可能**。`BMDSTATS=2/3` だけを理由に、存在する当該測定値を除外しない。

身長には `BMIHT`、体重には `BMIWT`、BMIには両方、ウエストには `BMIWAIST`、ヒップには `BMIHIP` を対応させる。ウエスト・ヒップの公開commentにはcode 1だけが確認されているため、値があるcomment保留区分は生じない。未知のコードが将来現れた場合は意味を推測せず処理を停止して**未確認・保留**とする。

数値欠損を補完せず、平均値置換・推定補完もしない。値域による自動外れ値削除、winsorization、丸め直し、単位変換、値の変更を行わない。非欠損値に対する追加の妥当範囲は**未確定**である。

| `BMXWT` 体重 | 5,983 | 81 | 5,757 | 226 | 29 | 45 | 7 | 0 | 0 |

`BMXBMI` の測定不能44件は、身長または体重の関連comment code 1の和集合であり、単純加算ではない。詳細なcomment・`BMDSTATS` 生コード件数、区分別件数、分類優先順位はmanifestを正本とする。個人行、`SEQN` 値・一覧、連続値別度数は保存していない。

## 5. 項目別の暫定処理と理由

| 項目 | 使用可能 | 除外 | 保留 | 採用理由／不採用理由 |
| --- | --- | --- | --- | --- |
| 身長 | 非欠損かつ `BMIHT=3` でない値 | 欠損かつ `BMIHT=1`、または欠損かつ `BMDSTATS=4` | 非欠損かつ `BMIHT=3`、その他欠損 | `Not straight` の意味は確認済みだが影響量は未確認。自動補正・除外を採用しない。 |
| 体重 | 非欠損かつ `BMIWT=3/4` でない値 | 欠損かつ `BMIWT=1`、または欠損かつ `BMDSTATS=4` | 非欠損かつ `BMIWT=3/4`、その他欠損 | 衣服・medical applianceの存在は確認済みだが補正量は未確認。仮の減算や一律除外を採用しない。 |
| BMI | 非欠損かつ関連する `BMIHT=3`、`BMIWT=3/4` がない値 | 欠損かつ `BMIHT=1` または `BMIWT=1`、または欠損かつ `BMDSTATS=4` | 元測定に品質commentがある非欠損値、その他欠損 | 派生値なので元の身長・体重commentを連動する。再計算・補完・丸め直しは採用しない。 |
| ウエスト | 非欠損値 | 欠損かつ `BMIWAIST=1`、または欠損かつ `BMDSTATS=4` | その他欠損 | 確認できたcommentは測定不能だけ。非欠損値を追加閾値で除外しない。 |
| ヒップ | 非欠損値 | 欠損かつ `BMIHIP=1`、または欠損かつ `BMDSTATS=4` | その他欠損 | 確認できたcommentは測定不能だけ。非欠損値を追加閾値で除外しない。 |

「使用可能」はこのQC工程で次の限定分析候補へ残せるという意味であり、モデル採用、母集団への一般化、完成品搭載を意味しない。

## 6. 未確認・保留事項と停止条件

- `BMDSTATS=4` またはcommentなし欠損の個別原因（未実施、非開示、amputation、妊娠その他）を集計だけから一意に対応づけることは**未確認**である。
- comment付き測定値の誤差量、補正可能性、用途別許容差は**未確認**である。このため値を変えず、現時点では保留する。
- 公開値に別の特殊欠損コードがあることは今回の5数値列では確認されず、無限値も0件だった。未知コードを検出した場合は停止する。
- 標本ウェイト、層化、クラスタリング、前処理、評価方法・採用基準、一般化可能性、詳細利用条件は今回決めていない。これらが決まり試験されるまでBは通過させない。

## 7. 再実行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-analysis.txt
.venv/bin/python scripts/download_nhanes_raw.py  # data/raw に公式XPTがない場合
.venv/bin/python scripts/summarize_nhanes_missing_qc.py
```

同一の受入済みXPTから生成したmanifestとGit上のmanifestが完全一致することを確認する。生データは `.gitignore` の `/data/raw/` 配下だけに置き、Gitへ追加しない。
