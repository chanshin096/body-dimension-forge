# テスト計画

身体寸法補完アプリの仕様を確認するためのテスト項目を記録する。

| ID | テスト項目 | 入力条件 | 期待結果 | 状態 |
| --- | --- | --- | --- | --- |
| T-001 | 正常入力 | 成人、人間、現実に近い体型、cm・kg単位の入力 | 入力値、推定値、自動計算値が区別される | 未実施 |
| T-002 | 空欄のキャラクター名 | キャラクター名を空欄にする | エラーにならず、計算には使われない | 未実施 |
| T-003 | 一部固定 | 身長、体重、胸囲、ウエスト、ヒップの一部を固定する | 再計算時に未固定項目だけ更新される | 未実施 |
| T-004 | 全部固定 | 身長、体重、胸囲、ウエスト、ヒップをすべて固定する | エラーにせず、整合性確認のみ行う | 未実施 |
| T-005 | 0や負数 | 身長、体重、胸囲、ウエスト、ヒップに0または負数を入力する | 警告または入力エラーを表示する。具体仕様は未確定 | 未実施 |
| T-006 | 単位間違い疑い | cm・kg単位として不自然な値を入力する | 警告を表示する。閾値は未確定 | 未実施 |
| T-007 | 極端値 | 対象範囲外の可能性がある極端な値を入力する | 警告を表示する。閾値は未確定 | 未実施 |
| T-008 | 再計算で固定値が変わらないこと | 固定済みの値を含む状態で再計算する | 固定値はアプリが勝手に変更しない | 未実施 |
| T-009 | BMIの自動計算 | 身長と体重を入力する | BMIは固定不可で、身長と体重から自動計算される | 未実施 |
| T-010 | 医療・健康評価をしないこと | 任意の入力 | 医療診断、健康評価、美容上の評価を表示しない | 未実施 |

## 未確定事項

- 入力エラーと警告の表示文言
- 単位間違い疑いの判定基準
- 極端値の判定基準
- 整合性確認の具体的な内容
